Builder.io visual-plan's typed-block authoring, reimplemented lean in C# feeding Guardrails. Format is
markdown + `:::` directives (Markdig), NOT real MDX (D1: ~90% of MDX's benefit without a JS runtime). The
review loop depends on the loopback SERVER, not the format. Distribution = C# native binary + Homebrew +
dotnet tool (ci/release/bump-tap ported from Guardrails). Positioning (docs/why-charter.md): the reviewed
front door to autonomous execution — Lavish/visual-plan stop at "looks good"; Charter feeds Guardrails.

hatch), symlink-escape rejection, at-least-once drain, self-healing ephemeral-port bind (IsPortConflict
walks the exception chain + matches the managed listener's "conflicts with an existing registration"
message — the cross-platform fix that unblocked v0.1.0). CI: classic .sln pinned to .NET 8.x; release via
workflow_run; TreatWarningsAsErrors. macOS binaries can't be stapled (server-side notarization). The full
