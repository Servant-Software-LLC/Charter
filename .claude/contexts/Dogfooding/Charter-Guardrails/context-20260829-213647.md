BLOCKERS/NOTES

- **NUGET HAS TWO INDEXES AND THEY LAG DIFFERENTLY.** Flat container first (~140s on 0.26.0, ~180s on
  0.25.0); the REGISTRATION index — which `dotnet tool update` resolves against — lags further and fails
  with *"is not found in NuGet feeds"*, which reads like the package was never published. Clearing the
  http-cache does NOT help. An explicit `--version` worked instantly on 0.25.0 and did NOT on 0.26.0, so it
  wins the race often, not reliably. **Poll the registration index, then install.**
- **A CI WATCH'S EXIT CODE IS NOT THE VERDICT.** `gh run watch --exit-status` returned 0 for a run whose
  conclusion was `failure`. Read `conclusion`, and check `headSha` equals the PR's `headRefOid` — a
  `gh pr update-branch` leaves the old run reporting success for a commit no longer in the PR.
- Standing authorization: **merge on green without asking**. Red still stops for a decision, unless it is a
  known filed flake in an area the change cannot touch.
- **The Python-heredoc pipeline EATS ONE LEVEL OF BACKSLASH.** `\\n` in a `<<'PY'` heredoc reaches the file
  as a real newline — five times this session, each breaking the C# build. Use Write/Edit for content with
  escapes, or build characters from code points (`(char)10`).
- Charter #212 made "no control character typed literally into a source file" a house rule.
- Do NOT kill dotnet/testhost machine-wide. A running suite holds the Core DLL and produces MSB3027 — wait
  for it rather than killing, especially with other agents on the machine.

New this session:

- **ONE `false` FOR TWO FACTS IS THE RECURRING BUG IN THIS CODEBASE.** #217 (probe: absent vs could-not-tell),
  #221 (`landChromeFocus`: no counterpart vs a counterpart that would not take focus), #223 (advisory:
  needed vs already done). Every time, the caller asserted the stronger fact. When a predicate returns a
  bare boolean, ask what the false MEANS.
- **A DISPLAY MARKER MUST NEVER BE THE SUBMITTED VALUE.** #125 established it for `(Recommended)`, #109 for

  verbatim, and write-in detection is the same ordinal comparison — so a marker in the value breaks three
  things SILENTLY. Assert values, not just labels.
